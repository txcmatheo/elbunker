# El Bunker Tracker

Pagina estatica para GitHub Pages que muestra el estado de supervivencia de los participantes de **El Bunker**.

## Uso En GitHub Pages

Pagina publica:

```txt
https://txcmatheo.github.io/elbunker/
```

## Importante

GitHub Pages no tiene servidor ni base de datos. Los cambios hechos desde el panel admin se guardan solo en el navegador donde se hacen. Para que todos los visitantes vean un cambio global, hay que editar el estado inicial en `script.js`, hacer commit y subirlo a GitHub.

## Caracteristicas

- Lista de 40 participantes con numeracion continua.
- Filtros por todos, vivos y muertos.
- Busqueda por nombre, numero, usuario de Minecraft o usuario de Kick.
- Avatares estilo Minecraft.
- Contador de vivos, muertos, creadores y streams en Kick.
- Diseno responsive para escritorio, tablet y celular.
